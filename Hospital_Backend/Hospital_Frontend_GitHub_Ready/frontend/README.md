# Hospital Frontend — React + Vite

Фронтенд для **уже готового Django-бэкенда Hospital**. Менять backend не нужно: Vite перенаправляет запросы `/api/` и `/media/` на Django `http://127.0.0.1:8000`.

## Быстрый запуск (Windows / PyCharm или VS Code)

1. Сначала запустите **отдельный** существующий Django-бэкенд (в папке с `manage.py`):

   ```powershell
   python manage.py migrate
   python manage.py seed_demo
   python manage.py runserver
   ```

   Django должен открываться по адресу http://127.0.0.1:8000/api/doctors/ . Если специализации/врачи уже созданы, `seed_demo` необязателен.

2. Откройте **новое окно терминала** в папке `Hospital_Frontend`, где лежит `package.json`:

   ```powershell
   npm i
   npm run dev
   ```

3. Откройте **http://127.0.0.1:5173/**.

**Важное:** если `npm` пишет «no package.json», вы находитесь не в той папке. Выполните `dir` и перейдите через `cd` в папку `Hospital_Frontend`, в которой расположен `package.json`. Нужен Node.js 18+ (предпочтительно Node 20/22).

## Страницы

- `/` — главная: герой с изображением врача, преимущества, специализации, врачи.
- `/doctors` — каталог: поиск, фильтр по специализации, сортировка.
- `/doctors/:id` — подробная информация о враче, расписание, отзывы, запись.
- `/specializations` — все направления.
- `/appointments` — свои записи, отмена, медицинская история после приёма.
- `/profile` — редактирование профиля.
- Модальные окна регистрации и входа; запись на приём с учётом расписания.

## Интеграция с Django

API использует **Token Authentication** с заголовком `Authorization: Token ...`. Токен хранится в `sessionStorage` текущей вкладки и удаляется после выхода. Бэкенд проверяет занятость даты и статусы записей, фронтенд не обещает, что предложенное время свободно до отправки запроса.

Прямые `/api/` ссылки работают **только при запуске Vite dev server** с proxy из `vite.config.js`. Для развертывания в интернет нужен отдельный прокси на сервере / настройка домена и безопасности. Это учебный проект: **не загружайте настоящие медицинские данные**.
